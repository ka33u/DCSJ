数据与结果的使用方式

  1. 原始型号数据

    型号库中的参数来自恢复的数据源。每次载入会显示原表、记录及文件来源。

  2. 本次计算结果

    只展示计算 API 实际返回的数值与曲线。修改参数后，已有结果会标记为过期。

  3. 未确认字段与计算限制

    未识别的字段完整保留。计算警告与引擎限制会显示在工作台中，供核对适用条件。

  4. 可复用的 HTTP API

    接口文档提供参数定义与在线请求入口。设计 JSON 可用于保存、迁移与集成。
